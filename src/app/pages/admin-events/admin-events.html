Import

Event-URLs serverseitig holen

Fuege hier Event-Links ein. Der Abruf laeuft serverseitig ueber Supabase in TypeScript und die Ergebnisse werden danach direkt in die `events`-Tabelle uebernommen.

Eine URL pro Zeile. Das ersetzt den alten JSON-Workflow komplett und funktioniert auch dann, wenn auf der Website keine lokale Event-Datei mehr liegt.
